عکسی که می‌خوای پس‌زمینه‌ی کل سایت بشه رو همین‌جا بذار، با اسم:

    bg.jpg

بعد توی js/data/site-config.js، توی آبجکت background:

    type: 'image'

رو ست کن (به‌جای 'grid'). اگه اسم یا فرمت فایل فرق داره (مثلاً bg.png)،
مسیرش رو توی همون آبجکت، فیلد imageUrl، عوض کن:

    imageUrl: 'assets/img/background/bg.jpg'

نکته‌ها:
- ترجیحاً عکس افقی (landscape) و حداقل عرض ۱۹۲۰px باشه تا روی صفحه‌های
  بزرگ کیفیتش افت نکنه.
- چون متن‌های سایت روی پس‌زمینه قرار می‌گیرن، بهتره عکس زیادی شلوغ/روشن
  نباشه. با imageOverlay (توی همون آبجکت background) می‌تونی تیرگیِ یه
  لایه‌ی روی عکس رو تنظیم کنی تا متن‌ها خواناتر بمونن (۰ = بدون تیرگی،
  ۱ = کاملاً مشکی؛ پیش‌فرض ۰.۶).
