# راهنمای معماری سایت

## معماری کلی

این سایت یک صفحه‌ی HTML استاتیک و داده‌محوره. تمام محتوای قابل‌تغییر سایت
(نام، مهارت‌ها، پروژه‌ها، دستاوردها، پست‌ها و...) داخل پوشه‌ی `js/data/` نگه
داشته می‌شه و در زمان بارگذاری صفحه توسط `js/app.js` روی HTML رندر می‌شه.

هیچ پنل مدیریتی، رمز عبور، یا ذخیره‌سازی در `localStorage` مرورگر وجود نداره؛
برای تغییر هر بخشی از سایت باید مستقیماً کد رو ویرایش کنی.

## چطور محتوا رو تغییر بدم؟

هر فایل داخل `js/data/` مسئول یک بخش از سایته:

| فایل | محتوا |
|---|---|
| `site-config.js` | نام، ایمیل، شبکه‌های اجتماعی، آمار هیرو، رنگ‌های پیش‌فرض |
| `skills.js` | لیست مهارت‌ها و درصدشون |
| `projects.js` | پروژه‌ها |
| `achievements.js` | دستاوردها / مدارک |
| `reels.js` | داده‌ی ریلز (در حال حاضر بخش «ریلز» صفحه با ویدیوهای استاتیک داخل `index.html` نمایش داده می‌شه) |
| `posts.js` | داده‌ی پست‌های فید (در حال حاضر بخش «پست‌ها» با کارت‌های استاتیک داخل `index.html` نمایش داده می‌شه) |
| `posts-settings.js` | تنظیمات پروفایل فید (نام، بیو، آمار، بنر اعلان) |
| `codes.js` | کتابخانه کد |
| `pdfs.js` | کتابخانه PDF |
| `videos.js` | داده‌ی ویدیوها (در حال حاضر بخش «ویدیوها» با کارت‌های استاتیک داخل `index.html` نمایش داده می‌شه) |
| `simlink-posts.js` | پست‌های صفحه سیمولینک |
| `chatbot-knowledge.js` | اطلاعاتی که ربات هوش مصنوعی درباره‌ات می‌دونه |

فقط کافیه یکی از این فایل‌ها رو با هر ادیتور متن باز کنی، مقادیر رو عوض کنی و
ذخیره کنی. برای بخش‌هایی که مستقیماً در `index.html` نوشته شدن (توضیح Hero،
کارت‌های پست‌ها، ویدیوها و ریلز)، ویرایش باید در همون فایل `index.html` انجام
بشه.

## چیزهایی که حذف شدن

- **پنل مدیریت (Admin Panel)** به‌طور کامل از کد حذف شد: فرم‌های ویرایش، ورود
  با رمز عبور، ذخیره‌سازی در `localStorage`، خروجی‌گرفتن HTML، پشتیبان‌گیری/
  بازیابی JSON، و ویرایش دسته‌جمعی متن‌های سایت — هیچ اثری از این‌ها در کد
  باقی نمونده.
- سیستم **آمار بازدید (Analytics)** که فقط برای نمایش داخل پنل مدیریت استفاده
  می‌شد هم حذف شد.
- رمز عبور پیش‌فرض پنل مدیریت که به‌صورت متن ساده داخل `site-config.js` ذخیره
  شده بود، حذف شد.

سایر بخش‌ها — چت‌بات هوش مصنوعی، سیستم رزرو جلسه، صفحه سیمولینک، افکت
shatter-glass، اینترو سینمایی، PWA و ظاهر/رنگ‌بندی/انیمیشن‌های سایت — بدون
تغییر باقی موندن.
