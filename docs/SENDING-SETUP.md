# راه‌اندازی ارسال پیام (تلگرام + ایمیل)

سایت بک‌اند نداره، پس برای این‌که پیام‌ها واقعاً به دستت برسن باید یکی از راه‌های زیر رو
فعال کنی. همه‌ی تنظیم‌ها در `js/data/site-config.js` هستن. هرچندتا رو پر کنی، پیام به همه‌شون می‌ره.
تا وقتی چیزی پر نشده، فرم‌ها پیام رو کپی می‌کنن و تلگرام رو برای ارسال دستی باز می‌کنن.

فرم‌هایی که از این سیستم استفاده می‌کنن: «درخواست پروژه»، فرم «تماس» و «گزارش لینک خراب ویدیو».

---

## ۱) ایمیل — Web3Forms (۲ دقیقه، رایگان)
1. برو به web3forms.com، ایمیل خودت رو وارد کن و «Create Access Key» بزن.
2. کلیدی که به ایمیلت میاد رو در `web3formsKey` بذار.
3. تمام. (کلید عمداً عمومیه و داخل سایت بودنش مشکلی نداره.)

جایگزین: Formspree. فرم بساز و آدرسش رو در `formEndpoint` بذار.

## ۲) تلگرام — پیشنهادی: Cloudflare Worker
چرا؟ توکن ربات مخفی می‌مونه و چون تلگرام در ایران فیلتره، سرور Cloudflare پیام رو
می‌رسونه و بازدیدکننده‌ی ایرانی هم می‌تونه بفرسته.

1. **ساخت ربات:** در تلگرام به `@BotFather` پیام بده، `/newbot` بزن و توکن رو بردار.
2. **شناسه‌ی چت خودت:** به ربات جدیدت یک پیام (مثلاً `/start`) بفرست، بعد این آدرس رو باز کن:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   عدد `"chat":{"id": ...}` همون `CHAT_ID`ـه.
3. **ساخت Worker:** در dash.cloudflare.com → Workers & Pages → Create → Hello World → Deploy،
   بعد Edit code و کل محتوای `serverless/telegram-worker.js` رو جایگزین کن و Deploy بزن.
4. **متغیرها:** Worker → Settings → Variables and Secrets:
   - `BOT_TOKEN` (نوع Secret) = توکن ربات
   - `CHAT_ID` = شناسه‌ی عددی
   - `ALLOWED_ORIGINS` = آدرس سایتت، مثلاً `https://amir.example` (چندتا با ویرگول)
5. آدرس Worker (مثلاً `https://contact.xxx.workers.dev`) رو در `telegramWorker` بذار.

> اگه روی گوشی خودت تلگرام اعلان نمی‌ده، یک بار به ربات پیام بده؛ ربات تا کسی بهش پیام نداده نمی‌تونه پیام بفرسته.

### راه سریع‌تر (بدون Worker) — ضعیف‌تر
`telegramBotToken` و `telegramChatId` رو مستقیم پر کن. ⚠️ توکن داخل کد سایت عمومی می‌شه و هرکسی
می‌تونه با ربات تو پیام بفرسته، و برای بازدیدکننده‌ی داخل ایران بدون VPN کار نمی‌کنه.
فقط برای تست مناسبه. اگه توکن لو رفت، در BotFather با `/revoke` عوضش کن.

## ۳) تست
1. سایت رو منتشر کن (یا با `python3 -m http.server`) و فرم «درخواست پروژه» رو پر کن.
2. باید پیام زیر فرم «پیامت از طریق … ارسال شد» رو نشون بده و در تلگرام/ایمیل بهت برسه.
3. اگه نشد: Developer Tools ← Network رو ببین. معمول‌ترین علت‌ها:
   - `ALLOWED_ORIGINS` با آدرس واقعی سایت (با `https://` و بدون `/` آخر) نمی‌خونه.
   - به ربات هیچ پیامی نداده‌ای.
   - کلید Web3Forms اشتباه کپی شده.

## محافظت از اسپم
- یک فیلد مخفی (honeypot) ربات‌ها رو بی‌صدا نادیده می‌گیره.
- هر مرورگر بین دو ارسال ۲۰ ثانیه صبر می‌کنه.
- Worker طول متن‌ها رو محدود می‌کنه و فقط از آدرس‌های مجاز پیام می‌گیره.
