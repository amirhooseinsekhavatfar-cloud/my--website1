● 01 — OVERVIEW

نگاه کلی

این پروژه از فایل‌های جدا برای هر بخش استفاده می‌کنه — یعنی برای تغییر «پروژه‌ها» فقط یه فایل رو باز می‌کنی، بدون این‌که با HTML یا CSS اصلی کاری داشته باشی.

✅
هر تغییری که توی فایل‌های js/data/ بدی، همون لحظه که فایل رو سیو کنی و صفحه رو رفرش کنی روی سایت دیده می‌شه — هیچ مرحله‌ی اضافه، ساخت، یا Bundle‌ای لازم نیست.
💡
قانون طلایی: محتوا (متن، عکس، ویدیو، لینک) همیشه توی پوشه‌ی js/data/ ـه. ظاهر و چیدمان توی css/ ـه. کارِ عمیق‌تر توی js/interactions.js و js/app.js.

● 03 — ADD / REMOVE

افزودن یا حذف یه آیتم

همه‌ی فایل‌های js/data/ از یه الگوی ساده پیروی می‌کنن: یه لیست از بلوک‌های { ... }.

برای حذف:

کل بلوک { ... } مربوط به همون آیتم رو با کاما بعدش پاک کن.

برای افزودن:

یه بلوک شبیه بقیه رو کپی کن، زیرش بچسبون (با کاما جدا کن)، مقادیرش رو عوض کن:

js/data/projects.js
{
  cat: 'plc',
  gradient: 'linear-gradient(135deg,#0D1319,#0d1b3e)',
  icon: 'fa-solid fa-microchip',
  featured: false,
  titleEn: 'My New Project',
  titleFa: 'پروژه‌ی جدید من',
  descEn: 'Short description here.',
  descFa: 'توضیح کوتاه اینجا.',
  tags: 'PLC,ESP32',
  github: '#',
  demo: '#'
}
⚠️
ترتیب و اسمِ فیلدها (titleEn, descFa و…) باید دقیقاً مثل بقیه‌ی آیتم‌ها بمونه، وگرنه سایت اون آیتم رو درست نشون نمی‌ده.
● 04 — IMAGES & VIDEO

افزودن عکس یا ویدیو (پروژه‌ها، پست‌ها)

عکس در پروژه‌ها:
  1. عکس رو آپلود کن: فایل عکس رو بریز توی پوشه‌ی assets/img/projects/.
  2. مسیرش رو بذار: توی js/data/projects.js، به همون آیتم یه خط اضافه کن:
مثال — عکس
image: 'assets/img/projects/plc-sim.jpg'
ویدیو در پروژه‌ها — فقط با لینک، بدون آپلود فایل:

لینک یوتیوب، آپارات، یا لینک مستقیم یه فایل mp4 رو بذار:

مثال — ویدیو
video: 'https://youtu.be/xxxxxxx'

وقتی video بذاری، یه دکمه‌ی «ویدیو» کنار GitHub/Demo اضافه می‌شه که با کلیک، ویدیو رو تمام‌صفحه پخش می‌کنه.

عکس و ویدیو در پست‌های فید:

دقیقاً همین دو فیلد توی js/data/posts.js هم از قبل کار می‌کنه:

js/data/posts.js
image: 'assets/img/posts/my-photo.jpg',
video: 'https://youtu.be/xxxxxxx'
💡
اگه image یا video نذاری، همون ظاهر پیش‌فرض (گرادیان + آیکون) نشون داده می‌شه — پس هیچ‌وقت چیزی خراب نمی‌شه.
● 05 — ENGINEERING TOOLS

اضافه‌کردن یه ابزار مهندسی جدید

  1. فایل HTML ابزار رو بذار: توی پوشه‌ی tools/ (کنار index.html).
  2. یه کارت جدید بساز: توی index.html دنبال id="eng-tools" بگرد، یه بلوک .tool-card کپی کن و مسیر/عنوان/توضیحش رو عوض کن.
  3. مسیر فایل رو بذار: توی onclick="openEngTool('...')" همون مسیر فایلت رو دقیق بنویس.
