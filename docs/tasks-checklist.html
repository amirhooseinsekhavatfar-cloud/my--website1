فوری — همین هفته

  • لینک‌های واقعی به ۶ پروژه اضافه کن
    همه‌شون توی js/data/projects.js فعلاً github: '#' و demo: '#' دارن — یعنی کلیک روی «GitHub» یا «Demo» جایی نمی‌بره. برای هر کدوم لینک واقعی بذار:
    • مجموعه شبیه‌سازهای تعاملی PLC • پلتفرم اتوماسیون PLC با کشیدن و رها کردن • داشبورد بهره‌وری شخصی (PWA) • وب‌سایت نمایشگاه لوکس کاشی و سرامیک • همین وب‌سایت پورتفولیو • کارت ویزیت تعاملی سه‌بعدی
  • فایل واقعیِ ابزار مهندسی رو جایگزین کن
    توی بخش «ابزارهای مهندسی» فقط یه کارت نمونه (PLC Simulator) هست که فایلش هنوز placeholder ـه. فایل HTML واقعی شبیه‌سازت رو بریز توی tools/ و مسیرش رو توی index.html (بخش id="eng-tools") تنظیم کن.
  • فایل رزومه (CV) رو وصل کن
    فیلد cv توی js/data/site-config.js خالیه. اگه دکمه‌ی دانلود رزومه‌ای جایی هست، الان به هیچ فایلی وصل نیست. فایل PDF رزومه رو بذار و لینکش رو اینجا اضافه کن.
🟡 CONTENT

محتوا — این هفته اگه وقت شد

  • عکس واقعی برای حداقل ۳ پروژه‌ی ویژه
    الان همه‌ی پروژه‌ها فقط گرادیان‌رنگی + آیکون دارن. اون ۳ پروژه‌ای که featured: true هستن («مجموعه شبیه‌سازهای PLC»، «پلتفرم اتوماسیون»، «داشبورد بهره‌وری») اول دیده می‌شن — برای همینا عکس واقعی بذار: assets/img/projects/ + فیلد image.
  • اگه ویدیوی دمو از پروژه‌ها داری، لینکش رو اضافه کن
    فیلد video رو توی همون فایل پروژه‌ها استفاده کن (لینک یوتیوب یا آپارات کافیه، نیازی به آپلود فایل نیست).
  • ۶ تا پست فید رو بازبینی کن
    توی js/data/posts.js — ببین محتوا و تاریخ‌ها هنوز به‌روزن یا نه.
  • آمار بخش هیرو رو چک کن
    statProjects: 15 و statYears: 3 توی site-config.js — هنوز عدد درستیه؟
🟢 TECHNICAL

فنی — بگو، من انجامش می‌دم

  • favicon رو با پالت جدید هماهنگ کن
    فاویکن فعلی هنوز از رنگ آبیِ برندِ قدیمی (#1E7FCC) استفاده می‌کنه، نه پالت کهربایی/فیروزه‌ایِ جدید سایت. یه بار می‌سازمش هماهنگ.
  • پیش‌نمایش شبکه‌های اجتماعی (og:image)
    وقتی لینک سایت رو توی تلگرام/واتساپ/لینکدین بفرستی، الان هیچ عکس پیش‌نمایشی نداره — فقط متن ساده. یه تصویر og:image طراحی می‌کنم.
  • sitemap.xml + robots.txt
    برای اینکه گوگل بهتر و سریع‌تر سایت رو ایندکس کنه.
  • تست روی سافاری، فایرفاکس، و یه گوشیِ واقعی
    تا الان تست‌ها بیشتر روی Chrome بوده. یه دور کامل چک می‌کنیم تا لِی‌آوت/چت‌بات/انیمیشن‌ها همه‌جا یکسان باشن.
